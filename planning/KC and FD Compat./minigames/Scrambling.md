# Scrambling

Second minigame, built to prove the shared systems are block-agnostic.

- Your original idea: "stir by moving the mouse, like making scrambled eggs".
- Judged on raw mouse travel speed (px/s), not a gesture shape. Ingredients jitter in place, more when you move faster.
- Everything else is the same as [[Stirring]]: basket, liquid, doneness, fail, serve.
- It is a copy-with-changes of the stirring screen, not a subclass. Decision: wait for a third minigame before extracting a shared base class ([[Decisions Log]]).
- **Not playtested by you yet** - speed band (400-2500 px/s) is a pure guess.
